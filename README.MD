# Video Translation Script using OpenAI Whisper and Google Translate

هذا السكريبت يقوم بترجمة الفيديوهات من أي من صيغ الفيديو الشائعة مثل `.mp4`, `.avi`, `.mov` إلى اللغة العربية. يستخدم السكريبت مكتبة **OpenAI Whisper** لاستخراج النص من الصوت في الفيديو، ومكتبة **Google Translate** لترجمة النص إلى اللغة العربية.

## المتطلبات

تأكد من أنك قد قمت بتثبيت المتطلبات التالية لتشغيل السكريبت بشكل صحيح:

1. Python 3.7 أو أعلى.
2. مكتبة `openai-whisper` لاستخراج النص من الصوت.
3. مكتبة `moviepy` لاستخراج الصوت من الفيديو.
4. مكتبة `googletrans` لترجمة النص.

### لتثبيت المكتبات المطلوبة:

```bash
pip install openai-whisper moviepy googletrans==4.0.0-rc1
```
تأكد من أنك قد قمت بتثبيت FFmpeg في جهازك (المطلوب لاستخراج الصوت من الفيديو). يمكنك تحميل FFmpeg من هنا.

كيفية الاستخدام
إعداد المجلدات:
ضع الفيديوهات التي ترغب في ترجمتها في مجلد videos.

السكريبت سيقوم بترجمة الفيديوهات وحفظ الترجمة في مجلد translated_videos الذي سيتم إنشاؤه تلقائيًا إذا لم يكن موجودًا.

تشغيل السكريبت:
بعد تثبيت المكتبات المطلوبة، قم بتشغيل السكريبت باستخدام:
```bash

python Main.py
```
سيقوم السكريبت بالبحث عن جميع الفيديوهات في مجلد videos، استخراج الصوت من كل فيديو، تحويل الصوت إلى نص باستخدام Whisper، وترجمة النص إلى اللغة العربية باستخدام Google Translate، ثم حفظ الترجمة في ملف .srt في مجلد translated_videos.

بنية المجلدات
videos/: يحتوي على ملفات الفيديو التي ترغب في ترجمتها.

translated_videos/: سيتم حفظ الترجمة هنا. يحتوي على ملفات .srt التي تحتوي على الترجمة إلى اللغة العربية.

ملاحظات
نموذج Whisper: يتم استخدام نموذج Whisper من OpenAI لاستخراج النص من الصوت. يمكنك اختيار النموذج الذي تريده، مثل "small" أو "large".

الترجمة: يتم استخدام مكتبة googletrans لترجمة النص إلى اللغة العربية.

دقة الترجمات: يمكن أن تختلف دقة الترجمة حسب جودة الصوت ومدى وضوحه.
